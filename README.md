# BanglaPay

Real-Time Mobile Financial Services Data Platform.

## Domain

A simulated Bangladesh Mobile Financial Services
ecosystem inspired by local MFS business processes.

## Source Systems

- Neon PostgreSQL
- MongoDB Atlas
- Confluent Kafka

## Technology

- Python
- PostgreSQL
- MongoDB
- Apache Kafka
- Avro
- Confluent Schema Registry
- Azure Databricks (planned)
- ADLS Gen2 (planned)

## Business Domains

- Customer Management
- Wallet Management
- Agent Network
- Merchant Management
- Transaction Processing
- Double-Entry Ledger
- Settlement
- Fraud Monitoring

## Data Generation

Manual batch execution by default.

Optional continuous Kafka streaming for
performance testing.

## Data Policy

All customer and financial records are synthetic.
No real customer financial information is used.
